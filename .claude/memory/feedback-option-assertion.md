**Why:** l'utilisateur vote sur ma description, pas sur le dépôt — une prémisse fausse produit une décision fausse et lui fait faire le travail de réfutation qui m'incombait.

**How to apply:** coller la sonde à côté de chaque option, ou l'énoncer explicitement comme non vérifiée ; quand un rapport d'agent contient déjà la mesure, le RELIRE plutôt que puiser dans mon souvenir. Corollaire : ne jamais conclure d'une sonde qui n'a pas tourné — une sortie visible VIDE avec un compteur non nul est une sonde cassée, pas un résultat.
