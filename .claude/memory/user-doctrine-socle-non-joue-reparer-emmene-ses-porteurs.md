**Verbatim (2026-07-26)** : « En tout cas les avantages de groupe doivent aussi fonctionner. Quand tu juge que l'existant n'est pas bon, tu dois t'assurer de migrer les éléments qui l'utilisent pour qu'ils fonctionnent aussi »

**How to apply :** une primitive n'est un modèle que si elle a déjà tourné en jeu ; le nombre d'entrées qui l'utilisent n'est pas une preuve. Sinon, un lot de vérification passe AVANT d'empiler dessus (registre, donnée, résolution, moteur, UI, puis recette). Toute réparation de socle migre ses porteurs existants pour qu'ils fonctionnent aussi.
