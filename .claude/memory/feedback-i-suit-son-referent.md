Verbatim utilisateur (2026-08-10) : « le (i) par convention est apres et non avant ceux a quoi il fait référence ».

**Why:** un glyphe placé avant son référent se rattache visuellement à ce qui précède — la position code l'appartenance.

**How to apply:** poser le glyphe d'aide après son référent, dans le même hit-target, insécable avec son texte ; « le i devant la Difficulté » désigne le PROPRIÉTAIRE de l'affordance, pas sa position — ne pas lire une préposition comme une spec de layout.
