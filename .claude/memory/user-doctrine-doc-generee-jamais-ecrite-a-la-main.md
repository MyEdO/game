**Verbatim (2026-07-27)** : « La documentation doit etre généré, jamais écrite a la main (vu qu'elle va périmer tres rapidement), depuis le code lui même comme on a fait pour Op/Flow. Ca doit etre généralisé pour tout. Et si cela demande de la discipline dans le code, on mettra de la discipline et des guards pour s'assurer que c'est respecté. »

**How to apply :** un fait vérifiable par la machine se DÉRIVE (générateur + garde), jamais recopié ; le manuscrit se limite à ce qu'aucune machine ne déduit (doctrine, arbitrage). Étendre le générateur plutôt qu'écrire une ligne à la main.
