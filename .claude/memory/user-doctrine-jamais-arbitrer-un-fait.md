**How to apply :**
- Classer avant de demander. Une question de FAIT (que dit le RAW, déduction depuis la règle générale comprise, structure du Round ou définition de l'Attaque ; ce champ a-t-il un lecteur ?) se MESURE, pièce regardée soi-même (Atlas, `Source/`, page du PDF, code) ; l'étiquette « à arbitrer » d'un agent est une affirmation à vérifier.
- Seuls le produit, le goût et un risque assumé se demandent, avec le coût de chaque option. Test : sans le bouton Recommandé, l'utilisateur peut-il répondre autrement sans contredire une doctrine écrite ?
- Le périmètre d'une question se lit au Source passage par passage. Une règle maison qui contredit un passage RAW explicite n'ouvre pas d'arbitrage : le RAW prime au passage qu'il couvre, la règle maison se borne au reste.
- Une réponse qui rappelle le RAW se consigne LECTURE RAW citée, jamais règle maison ; un code qui contredit le livre est une dette de fidélité, jamais une question.
