**Verbatim (2026-11-17)** : « Fable est bien pour le design et la 3D principalement mais opus est pas mal pour le reste » ; **verbatim (2026-11-18)** : « Utilise fable le moins possible, seulement sur les éléments de design. Ce qui fait partie du code pure c est à un autre modèle de le faire ».

**Why :** Fable coûte cher ; son apport est l'œil du dessinateur, pas l'écriture du code.
**How to apply :** une maquette, une pièce visuelle à dessiner ou un élément 3D (`modeleur`) partent sur Fable ; le portage d'un écran dans Godot (`ecraniste`), le code, la vérification et la lecture partent sur leur modèle de `calibrage.md`, jamais sur Fable.
