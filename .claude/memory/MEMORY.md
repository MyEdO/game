# Mémoire — Foundry/Game

> Une consigne neuve va au porteur de son déclencheur : règle `.claude/rules/<thème>.md`, skill, agent `.claude/agents/<x>.md` ou doc `docs/` (`.claude/rules/contexte-agents.md`).
> Une fiche ne naît que `user-*.md`, pour un arbitrage utilisateur cité verbatim et daté ; aucune autre fiche ne se crée (`scripts/guards/memoire-forme.mjs`).
> Les doctrines `user-*` se lisent dans `docs/doctrines.md` (GÉNÉRÉ par `scripts/docs/build-doctrines.mjs`). L'état d'un chantier vit sur son ticket.
