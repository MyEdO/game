# Solde #3181 — Filiation des processus lors de l’arrêt de Chrome — 2026-11-20

NATURE: corrigé

VERIFIE: Dans les deux phases de `killChromeTree`, une nouvelle filiation exige une naissance compatible avec celle du parent suivi, même lorsque le parent est absent. La date d’admission d’un PID est mémorisée, aussi pour les descendants découverts après le début de l’arrêt. Un remplacement observé borne les nouvelles adoptions. Un vrai orphelin né dans l’intervalle de vie de son parent reste détecté, y compris dans le relevé qui montre le remplaçant. Une naissance postérieure au début de l’arrêt reste exclue à la précision de la source. Les pauses, l’échéance calculée après l’arrêt et le diagnostic des vrais survivants sont couverts par les bancs existants.
