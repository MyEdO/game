# Solde #3915 — Références des rangées de Corruption — 2026-11-20

VERIFIE: les 486 rangées des 17 tables passent par ref('mutation', {min, max}). Le schéma refuse un identifiant inconnu et les bornes invalides. Le Compendium sélectionne la mutation par son libellé et exporte son identifiant avec les deux bornes. Les dés, les plages et les résultats ont été comparés à main.

## Mesures

Sur `ec1bc18e4`, `validateDataset('mutationTables.json', …)` rendait `null` pour un identifiant inexistant et pour une borne basse à 0. L’atelier refusait l’identifiant par un contrôle spécifique et acceptait la borne à 0 jusque dans son export. [Sonde sur main](https://github.com/MyEdO/game/issues/3915#issuecomment-7040247693)

La migration du 20 novembre convertit chaque rangée en `{ id, min, max }`. La rétroconversion reproduit exactement le document de départ. Le rejeu migre 0 rangée et conserve le SHA-256 `eac42c2c28130dc19d2226f785d7d23a52e9b98fa7e6130c3ab9ecfe46623ce4`. Les migrations antérieures qui écrivent les tables ont également produit zéro réécriture. Le patron canonique exige une occurrence par identifiant dans chaque table. Les données historiques satisfont déjà cette propriété.

La comparaison via `mutationAt` et `rollMutation` retrouve les mêmes résultats pour 1 700 jets directs et 3 383 tirages complets, toutes les faces des sous-tables comprises. Les 486 projections de rangée et les fiches Codex ont les mêmes empreintes. La revue a aussi contrôlé les liens inverses à chaque rangée.

## Écriture et refus

Le schéma refuse l’ancienne clé, la référence morte, les bornes hors dé, inversées ou fractionnaires, les trous et les chevauchements. La transaction de #4047 restaure l’entrée après un refus. L’atelier refuse le retrait d’une mutation désignée. Le test du pont Compendium traverse le choix dans le catalogue, l’enregistrement et la relecture canonique du JSON exporté. Le formulaire web partagé prend le relais du composant spécialisé.

Le cliquet des structures locales descend de 471 à 470 en retirant le site `src/data#mutationTables › [].entries[]`. Le catalogue `mutations.json` et sa définition `schemas/defs/mutations.ts` sont identiques à la base.
