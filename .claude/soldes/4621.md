# Solde #4621 — Consulter le plan du périmètre en lecture seule — 2026-11-21

NATURE: corrigé

VERIFIE: `test:perimetre -- --liste` produit un plan sans écriture dans le dépôt quand le détenteur du verrou des gestes lourds lui transmet son jeton. Un accès Git qui interdit la prise rend 75 et indique comment obtenir cette admission. Une rotation de détenteurs ne prolonge plus l'attente de consultation au-delà du délai commun.

## Consultation sous le verrou des gestes lourds

Le parent autorisé acquiert `prendreVerrouAsync({ ...verrouGestesLourds(racine), env })` dans sa vue inscriptible du dépôt. Il attend le verdict `pris`, puis lance `npm run test:perimetre -- --liste --base <ref> --budget 45` dans la vue en lecture seule avec `{ ...env, ...prise.env }`. Les deux vues donnent le même chemin absolu au Git commun et à son verrou et voient le PID du détenteur. Le parent garde la prise pendant l'observation et libère après la fin confirmée de l'enfant et de ses descendants. Le jeton reste dans l'environnement de l'enfant. Le parent consacre sa prise à cette consultation pendant ce temps.

Les lectures de l'arbre de travail utilisent le diff et le listage Git habituels. Le journal dit que le plan ne rapatrie ni ne met à jour les durées. La supervision et la dérivation bornées créent leur entrée, leur sortie, leur marqueur et leur journal sous le dossier temporaire externe. Sur un dépôt inscriptible, le CLI peut toujours prendre le verrou lui-même. En cas de contention, il utilise les annonces et le pas du verrou commun avec, pour la consultation, un plafond global égal à l'échéance par détenteur. [Cadrage mesuré avant le correctif](https://github.com/MyEdO/game/issues/4621#issuecomment-7056059755)
