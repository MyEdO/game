La 5ᵉ copie aurait été celle du serveur, qui s'en sert à la place. Une course conclue `failure` dont aucun job n'est rouge et dont au moins un est `cancelled` est `annulee` : c'est la forme réelle de #1853, run 37365832262. Le motif du runner est lu dans les annotations du check-run du premier job annulé (« The job was not acquired by Runner of type hosted even after multiple attempts »).

Train local, étape `file` :
- une course de branche annulée sous `PLAFOND_RELANCES` (3) se dit (jobs, motif, essai n/3) et le train veille ; au plafond, le train rend un rouge nommé avec le geste `gh run rerun <id> --failed` puis `--reprendre` ;
- une course de FILE annulée re-demande la fusion sur la même tête, sans fusion de main, dans `BORNE_EJECTIONS` ;
- les courses de file terminées avant la demande sont écartées (`coursesDeFileTerminees`) et ne jugent plus la demande.

Reprise serveur (`reprendre-file.mjs`) : une course de branche annulée, plus vieille que `DELAI_RELANCE_MS` (10 min), est relancée par `POST actions/runs/<id>/rerun-failed-jobs`. Au 3ᵉ essai, le statut est `plafond` et le geste humain est nommé ; chaque statut est signalé par commentaire idempotent. `reprise-file.yml` passe à `actions: write` (accord de l'utilisateur à la question posée le 2026-10-07 : « Oui, appliquer (Recommandé) »).

## Réfutation
verdict: CONFIRMÉ

Le juge (lecture seule) a réfuté le design avant le code, avec 3 sondes au scratchpad. Ce qu'il a établi :
- la cause RÉELLE (repli mort par égalité stricte), à la place de l'hypothèse du compte ;

- le passage par `reprendreApresEjection` était FAUX : il fusionne main, puis retrouve la même vieille course annulée et fait une 2ᵉ éjection. Il est remplacé par la redemande, avec les courses terminées écartées ;
- le faux « absente » se corrige par « aucune course jamais vue », pas par « depuis la dernière vue » ;
- `reprendre-file.mjs` ne peut pas importer `etapesDuTrain.mjs` (`semver` sans `npm ci` côté serveur), d'où le déplacement dans `coursesCi.mjs` ;
- le motif du runner se lit dans les annotations.
