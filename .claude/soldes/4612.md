## Réfutation

verdict: CONFIRMÉ — Comparaison profonde sur le corpus, rejeu sous contention et injection dans la vraie garde.

- Le lexeur remplace des caractères par des espaces et conserve tous les autres à leur position. Les accès directs et crochets exigent `def` dans la source. Les appels et déstructurations exigent `defDe`. Un alias exige une assignation depuis `defDe` quelque part dans le même fichier. Le filtre examine donc le fichier entier au niveau du détecteur.
- Comparaison profonde dans l’ordre du corpus des triplets `[fichier, ligne, extrait]` avec les 13 champs de la grammaire. SHA-256 JSON commun `f0fcb935b8f2aa567a2013db9460cd21dc49f8c85becab6849cb70af44809b56`. Les trois triplets visent `descente.ts`, lignes 43, 221 et 222. Zéro diagnostic hors du foyer.
- Huit tests Node verts. Ils exercent les accès directs dont `_def`, trois délimiteurs de chaîne dans les accès par crochets, les champs d’enfants, alias typés et assignés sur plusieurs lignes, appels imbriqués, déstructurations avec annotation, commentaires, chaînes et substitutions de gabarit.
- La vraie garde rend le code 1 sur `scripts/temoin-lecture-4612.mjs:1 export const lireForme = (noeud) => noeud._zod.def;` après 6 404 ms. Le témoin est retiré et le rejeu rend le code 0 avec les deux tests verts.
- `npm run typecheck:fast` donne zéro erreur. `npm run test:perimetre -- --base f5d9d2144ef106e2562023e28e0cde4e04206625 --budget 0` vérifie le lint des deux fichiers et les huit tests du banc touché.
