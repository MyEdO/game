Design jugé : issuecomment-5925375332.
- `build-all --mixtes` joue `perimetreDesMixtes`, dérivé de la table (générateurs de code + générateurs à `injecte` non vide : gen-registry, build-atlas-index, build-implemente), sans enregistreur. Il ne réécrit pas `SOURCES_LUES`.
- `touchesDocSources(…, { seulement })` restreint la mesure à ce périmètre ; un membre absent de la mesure fait régénérer.
- Les ANCÊTRES d'un chemin sont testés contre les `dossiers` (classe « dossier neuf », antérieure).
- L'étape `docs` du train appelle `--mixtes` ; le hook garde son `docs:build` complet.
- Mesure : `build-all --mixtes` = 45 s, contre 125-203 s.
- 8 mutations rouges, une par règle (restriction, membre absent, ancêtres, `--mixtes` débranché, périmètre sans `injecte`, étape en `--quiet`…).

Invariant : corps de #2193, l'étape `docs` « régénère et COMMET les docs dérivés — elle fait foi ». Question : pendant le train, qui régénère les dérivés, et combien de fois ?
