# Solde #3503 « Le test de siège dépend de l'ordre des fichiers » — 2026-11-06

NATURE: corrigé

VERIFIE: la fuite est une ACTION du store substituée par un banc. `src/state/offresUtilisables.test.ts` pose `jouerAction: vi.fn()` ; la remise à plat de `src/test-setup.ts` ne rendait que les DONNÉES (le JSON retire les fonctions, le merge partiel de zustand garde l'action courante) : tout fichier suivant du worker cliquait un meuble qui ne jouait plus rien, d'où `src/state/seating-interaction.test.ts:64`. Reproduction déterministe : un worker, `offresUtilisables` puis `seating-interaction` (séquenceur ordonné), rouge à l'identique ; vert après le correctif. Relevé sur la suite entière (sonde `afterAll` qui compare chaque action à `getInitialState()`) : 3 fichiers fautifs (`offresUtilisables` → `jouerAction`, `src/ui/CarnetScreen.test.tsx` → `toggleCluePin`, `src/ui/wrap-keyboard-vs-cursor.test.tsx` → `commitCursor`), `jouerAction` hérité par 229 fichiers du même worker. Correctif de classe : `etatViergeDuStore` (actions de l'état initial sous une copie neuve des données), en `beforeEach` et en `afterAll`. Garde : `src/test-setup-actions-du-store.test.ts`, rouge (3/3) sur l'ancienne remise à plat. Les restaurations d'actions à la main que la remise à plat rend redondantes partent (`useStagePointer`, `stage-pinch`, `inspecter-au-geste`, `escalade-et-chute-par-l-arete`, `structure-par-l-arete`, `clics-du-champ-invite`, `dialogue-touches`).

- `netFlow.originals` (`src/state/netFlow.ts:108`), enrobage d'invité laissé posé : aucun fichier ne le laisse sur la suite entière (sonde ci-dessus, aucune action de `GUEST_INTENTS` relevée) -> RAS : sans objet

## Réfutation
verdict: CONFIRMÉ
Attaque : un banc qui pose une sonde d'action en `beforeAll` pour tous ses tests la perdrait au `beforeEach` global. Réponse : les données étaient déjà remises à plat avant chaque test, et la suite entière reste verte avec les actions remises.
