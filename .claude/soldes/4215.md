## Sonde minimale du moteur

Dans un projet Godot vide, placer ce script en `sonde.gd` et lancer `xvfb-run -a "$GODOT" --path . --rendering-method forward_plus --audio-driver Dummy --script res://sonde.gd -- --changer`. Rejouer avec et sans `--changer` sous chacun des deux rendus.

```gdscript
extends SceneTree

func _initialize() -> void:
	_jouer.call_deferred()

func _jouer() -> void:
	var camera := Camera3D.new()
	root.add_child(camera)
	camera.current = true
	var lampe := OmniLight3D.new()
	lampe.omni_range = 10.0
	lampe.light_cull_mask = 1
	root.add_child(lampe)
	var piece := MeshInstance3D.new()
	piece.mesh = BoxMesh.new()
	piece.position.z = -2.0
	root.add_child(piece)
	for image in 5:
		await RenderingServer.frame_post_draw
	if "--changer" in OS.get_cmdline_user_args():
		piece.layers = 2
	for image in 5:
		await RenderingServer.frame_post_draw
	lampe.queue_free()
	for image in 5:
		await RenderingServer.frame_post_draw
	quit()
```

Forward+ avec changement donne deux `unpair` pendant la libération de la lampe et sort avec le code 0. Les trois autres passages donnent zéro. Godot a corrigé en amont le désappariement des géométries avant modification de leur couche. Le binaire épinglé précède ce commit. [Rapport Godot #121989](https://github.com/godotengine/godot/issues/121989) · [Correctif Godot #122064](https://github.com/godotengine/godot/pull/122064)
