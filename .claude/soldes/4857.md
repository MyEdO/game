# Solde #4857 — Gantelet verrouillé porté : la retenue de l'objet tenu atteignable en jeu — 2026-11-24

NATURE: corrigé

VERIFIE: Le gantelet verrouillé se porte depuis la fiche (`isWearable`, geste « porter ») sans prendre la main d'arme. Un gantelet porté couvre la main d'arme, deux portés couvrent les deux mains, un gantelet tenu couvre sa main ; tenu et porté sont exclusifs (`peutEtreTenu`), et `ganteletsAuxMains` borne leur nombre à deux mains, dans chaque set (troisième porté : le premier s'ôte ; refus au port ou en main au-delà). Tout lâcher forcé passe par `ganteletRetient` : Piège-lame (`applyBladeTrap`) et op `disarm` (Critiques, Main ensanglantée par `glisseDeLaMain`, dont l'Action se poursuit quand rien n'a glissé). La retenue est un effet actif −20 aux Tests de la main tenue, valeur en donnée (`regles.json` `retenue-du-gantelet-verrouille`, AA 08 l.236), pour le Round entamé et le suivant ; un second évènement pendant la période fait tomber l'objet (AA 08 l.238). Le drapeau `gauntletSavedRound` et l'ancien lecteur `lockedGauntletHolds` sont supprimés. `src/noyau/locked-gauntlet.hors-store.test.ts` : 23 tests au banc du noyau par les gestes du joueur, chaque correctif prouvé par mutation rouge. `npm run typecheck` code 0 ; suite Vitest complète verte.

## Réfutation

verdict: CONFIRMÉ

Deux tours de juge frais. Tour 1 PARTIEL, deux bloquants, corrigés et couverts : un gantelet pouvait être à la fois porté et tenu, et le plafond de deux mains ignorait le gantelet tenu (désormais exclusifs, comptés ensemble, refus aux deux gestes) ; sous Main ensanglantée, le gantelet retenait l'arme mais l'Action était annulée (désormais `glisseDeLaMain`, partagé par le joueur et l'IA, poursuit l'Action). Remarque traitée : le manifeste des primitives dit la période de deux Rounds. Tour 2 PARTIEL, un bloquant corrigé et couvert : le plafond ne comptait que les gantelets du set actif, et changer de set pouvait mettre trois gantelets sur deux mains (`ganteletsAuxMains` compte désormais le set qui en tient le plus). Remarques traitées : les commentaires d'`isWearable`, de l'Encombrement porté et de la dotation disent le gantelet qui se porte ; `Main` dérive de `MAINS`, liste unique des deux mains. Remarque sans suite : une dotation de plusieurs gantelets ne se rencontre dans aucune donnée. La fusion 2b3d1a217 garde la fiche de main, où une arme est équipée si elle est tenue dans le set actif, et y fait passer ce qui se porte par `isHeld`, pour que le gantelet porté reste dit équipé.
