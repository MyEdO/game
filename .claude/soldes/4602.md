# Solde #4602 — Veille sur un journal en lecture seule — 2026-11-20

NATURE: corrigé

VERIFIE: le CLI réel suit un run vivant et restitue un verdict écrit sans préparer le cache ni prendre le verrou de constat. Pour une interruption, il relit le run sous verrou avant d’écrire sa preuve atomique. Si le constat est impossible et qu’aucun verdict durable n’apparaît à la relecture, la veille rend 6 avec un diagnostic `[veille]`. Les erreurs d’écriture hors veille remontent.

## Mesures

- À `0ab8e0fe43a7e3a2a74f08c6e38c12dbbea7c98a`, le vrai `--veiller` rend 4 et `PUBLICATION: rouge moteur — EROFS` sur le temporaire du verrou pour un journal vivant et pour un verdict vert déjà publié. L’injection cible uniquement l’écriture du temporaire. Les octets du journal restent identiques. [Re-mesure au ticket](https://github.com/MyEdO/game/issues/4602#issuecomment-7050707343)
- Sur le candidat, `--veiller` et `--constat` suivent le run vivant jusqu’à `PUBLICATION: vert`, code 0, et lisent également ce verdict au démarrage. Le banc fait refuser la création du cache, le verrou et la mesure d’identité. Un PID dont l’existence est établie malgré `EPERM` reste vivant quand la naissance est inaccessible.
- La mort prouvée avec verrou en lecture seule donne le code 6, nomme `EROFS` et conserve le journal et le log à l’octet. Avec écriture autorisée, la même mort en `file` produit la transition et le verdict rouge moteur documentés, code 4. Si seul l’append au log échoue, la veille signale `EACCES` et restitue la preuve durable du journal. Le bloc commun au train hors veille rend toujours 4 sur `EROFS`.
- Le banc concurrent remplace le run, puis publie un verdict du même run pendant l’attente du verrou. La relecture sous verrou laisse les deux preuves intactes. Un verrou tenu jusqu’à son échéance donne une limitation après 10 s d’horloge injectée, sans nouveau cycle de veille.
- `npm run typecheck:fast` donne zéro erreur après `npm run gen`. Les trois bancs #4602 passent. Le rejeu ciblé de publication, fermeture, PID, verrou et écriture atomique compte 277 succès et deux cas écartés pour la supervision locale.
