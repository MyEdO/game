# NAVIGATION MARITIME • **Piloter un navire sur les mers et éviter les périls des océans** •

**La Mer des Griffes** présente plusieurs séries de règles différentes pour les bateaux en fonction de différentes circonstances. Ces règles sont réparties comme suit :

**Navigation maritime** (le présent chapitre) donne les règles de base pour progresser, manœuvrer, s'orienter et combattre sur un bateau. Ces règles sont prévues pour de petits navires effectuant des voyages courts, à bord desquels les Personnages sont plus nombreux que les PNJ. En d'autres termes, si le groupe veut faire voguer sa barge sur les flots marins pendant quelques jours, il suffit d'utiliser ce chapitre.

**Navigation à bord de grands vaisseaux** (page 121) donne des conseils sur ce à quoi ressemble la gestion d'un navire quand les actions des individus ont moins d'importance que la coordination d'un grand équipage. Dans les situations où les Personnages sont en minorité, par exemple s'ils rejoignent le contingent d'un navire de guerre impérial le temps d'un scénario, vous pouvez utiliser ces règles.

**Longs voyages** (page 128) fournit une version des règles d'Activités de **WFJDR** conçue pour les longs trajets en mer. Dans les cas où le Meneur doit faire jouer un voyage épique, mais veut atteindre la destination sans devoir décrire le déroulé des événements jour par jour, il peut se servir de ces règles.

# **PETITS NAVIRES SUR L'OCÉAN**

Des règles de Navigation fluviale ont été intégrées à **Warhammer Fantasy le Jeu de Rôle** dans le **Compagnon de Mort sur le Reik**, et les petits navires fluviaux sont aussi utilisés sur l'océan. Les baies et les estuaires du nord de l'Empire accueillent de nombreux bateaux de pêche et petites barges commerciales. Ces navires ont une apparence et un fonctionnement semblables à ceux des embarcations décrites pour le voyage fluvial. Pour une explication plus détaillée de ces règles, reportez-vous au **Compagnon de Mort sur le Reik**, mais n'oubliez pas que les règles du présent supplément sont moins clémentes, car les Personnages qui ne possèdent pas la Compétence Voile sont incapables de piloter un bateau à voile sur l'océan et vous êtes obligé d'effectuer des Tests de Compétences pour progresser.

- 0 « Tests de Navigation » est un terme générique pour désigner les Tests de Compétence nécessaires afin de s'assurer qu'un navire progresse sur son trajet et effectue ses manœuvres de manière appropriée.
- 0 Si le vaisseau est propulsé par ses voiles, le Test de Navigation est effectué à l'aide de la Compétence Voile du Personnage à la barre, voir ci-dessous.
- 0 Si le bateau est propulsé par ses avirons, le Test de Navigation est effectué en utilisant la Compétence Ramer du rameur possédant le score le plus élevé dans cette Compétence (mais les autres rameurs peuvent apporter leur Soutien).
- 0 Les personnages dotés de la Compétence Savoir (Océans) peuvent bénéficier d'un bonus sur les Tests de Navigation égal au premier chiffre de leur score de Compétence. Par exemple, un personnage possédant une Compétence Savoir (Océans) de 36 recevrait un bonus de +3 sur les Tests de Navigation. Ce bonus ne s'applique que sur l'océan.

# **Le Personnage à la barre**

Quand elles indiquent qu'un Test de Navigation est nécessaire, les présentes règles vont souvent mentionner le Personnage à la barre. Ce terme désigne le Personnage qui est le mieux placé pour influencer le mouvement concret du vaisseau au moment du Test. Il peut recevoir le Soutien d'autres Personnages comme expliqué en page 155 de **WFJDR**. Le Personnage à la barre ne doit pas nécessairement être littéralement à la barre : il peut manier le gouvernail, les voiles, ramer sur le bateau ou occuper n'importe quelle position depuis laquelle il peut déterminer la direction du navire.

# **Forcer le rythme**

Un équipage peut tenter d'augmenter la vitesse de son vaisseau, soit en s'efforçant de prendre le vent de la meilleure manière possible, soit en ramant plus vigoureusement. Mais la vitesse que peut gagner un bateau par ce biais est limitée, et pour bénéficier du bonus de Mouvement, un Test de **Voile** ou de **Ramer** doit être réussi comme expliqué dans le tableau qui suit. **Note :** ce Test n'est pas un Test de Navigation et Savoir (Océans) ne donne donc pas de bonus dessus.

| FORCER LE RYTHME               |                    |                         |  |
|--------------------------------|--------------------|-------------------------|--|
| Bonus de M<br>Voile<br>Avirons |                    |                         |  |

|                                | Difficile (–30)    | (–20)                   |  |
|                                |                    | Test de Ramer Très      |  |
| +2                             | n/a                | Difficile (–30)         |  |

Le bonus de Mouvement dure jusqu'à la prochaine Période de travail (8 heures pour les voiles et 2 pour les avirons) ou jusqu'à ce que les circonstances exigent un Test de Navigation.

### **Épuisement**

Faire avancer un vaisseau est un travail rude. À la fin d'une Période de travail, les membres d'équipage impliqués dans le maniement des voiles ou des avirons doivent réussir un Test de **Résistance Accessible (+20)** sous peine de recevoir un État *Exténué*. Si ces membres d'équipage ont Forcé le rythme (voir ci-dessus), ce Test devient un Test de **Résistance Complexe (–10)**.

# **MANŒUVRES**

Les navires doivent parfois exécuter des manœuvres compliquées pour éviter les obstacles ou pointer leurs canons sur un ennemi.

# **Tests de Manœuvre**

Chaque fois qu'une Manœuvre est nécessaire, le Personnage à la barre effectue un Test de Manœuvre. Il s'agit d'un Test de Navigation modifié par la Caractéristique Man du bateau, ainsi que par les autres facteurs que le MJ juge pertinents. Les Tests de Manœuvre sont un type de Test de Navigation et tous les modificateurs qui s'appliquent aux Tests de Navigation s'appliquent aussi à eux. À noter cependant que les facteurs détaillés dans cette partie s'appliquent uniquement aux Tests de Manœuvre, et n'influencent pas les Tests de Navigation effectués pour autre chose.

# VITESSES MAXIMUM

Il existe plusieurs façons d'améliorer sa vitesse pour un vaisseau, mais dépasser la vitesse pour laquelle il a été conçu soumet un bateau à des forces qui peuvent l'endommager.

Un bateau peut se déplacer à un rythme allant jusqu'à M+4 sans risquer de subir des Dégâts. Un navire qui se déplace au-delà de cette vitesse doit réussir un **Test d'Endurance** sous peine de subir des Dégâts conformément à ce qu'indique le tableau Ça va lâcher, capitaine !

# **Salissures**

Avec le temps, un bateau qui reste sur l'océan commence à accumuler une couche d'algues et de coquillages sur sa coque, ainsi que des tarets et des coléoptères xylophages dans son bois. La fiabilité d'un vaisseau est compromise par ces infestations.

Pour chaque semaine qu'un navire passe en mer sans l'entretien approprié, effectuez un Test de Résistance pour le vaisseau. Pour chaque Test raté, ajoutez un niveau de Salissures, qui a les effets décrits dans le tableau Salissures.

Les Salissures peuvent être retirées des petits navires en utilisant les Compétences, les Sorts ou les Miracles de manière créative ou même en échouant le bateau et en le nettoyant à la main. Mais pour récurer un bateau de Taille Moyenne ou plus, il doit être emmené dans une cale sèche prévue à cet effet afin de gratter sa coque.

# **Température**

Les températures élevées ou basses peuvent avoir des effets importants sur l'efficacité d'un équipage.

### **Caniculaire**

Toutes les deux heures, effectuez un Test de **Résistance Intermédiaire (+0)**. En cas d'échec, vous subissez les effets de l'Exposition à la Chaleur comme expliqué en page 181 de **WFJDR**. Chaque membre de l'équipage doit boire environ quatre litres d'eau par jour sous peine de souffrir de la Soif, comme expliqué en page 181 de **WFJDR**.

#### **Chaude**

Toutes les quatre heures, effectuez un Test de **Résistance Accessible (+20)**. En cas d'échec, vous subissez les effets de l'Exposition à la Chaleur. Chaque membre de l'équipage doit boire trois litres d'eau par jour sous peine de souffrir de la Soif.

#### **Médiane**

La température est modérément froide ou chaude. Elle est tolérable et n'a pas d'effet sur l'équipage.

#### **Froide**

Toutes les quatre heures, effectuez un Test de **Résistance Accessible (+20)**. En cas d'échec, vous subissez les effets de l'Exposition au Froid comme expliqué en page 181 de **WFJDR**.

#### **Glaciale**

Toutes les deux heures, effectuez un Test de **Résistance Intermédiaire (+0)**. En cas d'échec, vous subissez les effets de l'Exposition au Froid.

#### **Affaler les voiles**

De forts vents menacent d'endommager les voiles et le gréement. Dans de telles conditions, l'équipage ne peut pas faire grand-chose à part bien fixer tout ce qui s'attache et prier pour que Manann décide de calmer les mers.

Il faut réussir un Test de **Navigation Intermédiaire (+0)**  pour abaisser les voiles à temps. En cas d'échec, le bateau subit immédiatement un Critique sur ses voiles, car elles sont malmenées par les vents puissants.

Tant que les vents continuent de souffler à cette intensité, un vaisseau qui les subit doit jeter une Ancre, sinon il se déplace à 25 % de sa vitesse normale dans la direction dans laquelle le vent le pousse.

#### **Encalminé**

Le bateau ne peut pas se déplacer grâce à ses voiles. À moins qu'il ait une méthode de propulsion de secours, soit le navire reste en place, soit il est tiré dans la direction du courant (la force des courants varie, mais la plupart entraînent les vaisseaux à un rythme de Mouvement de 1 ; les courants de marée ou ceux menant vers un tourbillon les tirent plus rapidement, voir pages 112 et 113.

Si le vaisseau possède une Embarcation de bord équipée d'avirons, elle peut être mise à l'eau pour remorquer l'autre bateau plus grand. Dans ce cas, les deux navires se déplacent ensemble comme s'ils n'étaient qu'un seul et même vaisseau avec un M de 1 et subissant –4 DR à sa Caractéristique Man.

#### **Virement de bord**

Le Mouvement du navire peut être augmenté en virant de bord, ce qui nécessite un Test réussi de **Navigation Intermédiaire (+0)**. En cas d'échec, le bateau se déplace normalement, sans bonus.

# **COURSE-POURSUITE**

Les règles de course-poursuite sont une adaptation des règles de Poursuite sur terre (voir **WFJDR**, p. 166). Cependant, comme l'échelle de ces poursuites est beaucoup plus vaste en mer, faire jouer une Poursuite en utilisant les règles terrestres pourrait prendre beaucoup de temps. C'est pourquoi, sauf si les équipages des bateaux impliqués dans la Poursuite interagissent d'une autre manière (par exemple se tirent dessus au canon, lancent des Sorts, etc.), nous vous recommandons de demander des Tests pour déterminer la Distance tous les dix Rounds et de multiplier les résultats par dix pour définir la véritable Distance.

Si les résultats des Tests indiquent que les bateaux sont maintenant dans une position où les équipages peuvent commencer à interagir l'un avec l'autre, les Tests pour déterminer la Distance doivent de nouveau être effectués à chaque Round normalement.

Si l'équipage d'un vaisseau veut capturer un autre vaisseau, lui échapper ou le prendre de vitesse de toute autre manière, le MJ doit gérer l'écart entre les deux. Chaque bateau impliqué dans la course est considéré comme un individu. Le navire (ou le groupe de navires alliés) poursuivi est appelé la Cible et ceux qui essaient de l'attraper sont appelés les Poursuivants. Si les deux camps font la course et si les Poursuivants dépassent la Cible avant la ligne d'arrivée, ils deviennent eux-mêmes la Cible.

**1 : Déterminer la Distance :** le MJ définit un nombre représentant la l'avance que la Cible a sur les Poursuivants. Si il y a plusieurs poursuivis et/ou poursuivants, utilisez le membre de chaque groupe le plus proche de l'autre groupe. Cette longueur est la Distance. Chaque point de Distance équivaut à 10 mètres. La Distance va de 0 (la Cible est attrapée) au nombre que le MJ juge approprié pour indiquer que la Cible a définitivement semé le Poursuivant au vu de l'environnement. Plus l'environnement est encombré, plus le nombre que la Cible doit atteindre pour fuir est bas.

| Environnement dans lequel a<br>lieu la poursuite                       | Distance<br>nécessaire<br>pour s'échapper |
|------------------------------------------------------------------------|-------------------------------------------|
| Bancs d'un épais brouillard, formations<br>rocheuses labyrinthiques    | 10                                        |
| Faible lumière, fjords ou criques                                      | 30                                        |
| Légère brume, beaucoup de rochers et<br>de bancs de sables à proximité | 50                                        |
| Haute, mer un peu houleuse                                             | 70                                        |
| Haute, mer d'huile, temps dégagé                                       | 100                                       |

Si la Cible est constituée d'un groupe en formation resserrée, tous les membres du groupe sont considérés comme se trouvant à la même Distance, mais si l'un d'entre eux a une avance sur le Poursuivant supérieure de plus de 16 mètres à celle d'un autre membre de la Cible, calculez sa Distance individuelle d'avec les Poursuivants de manière appropriée.

Les Poursuivants peuvent être considérés comme un groupe s'ils ont tous le même Mouvement ou divisés en petits groupes en fonction de leur Mouvement ou de leur capacité à réussir des Tests de poursuite.

<span id="page-113-0" data-folio="110"></span>
**Exemple :** un langskip norse tente de rattraper une caraque impériale. Le langskip est doté d'un M de 6 en utilisant ses Avirons tandis que la caraque a un M de 5 en employant ses Voiles.

Le MJ décide que la poursuite commence alors que le langskip se trouve hors de portée des canons de la caraque. Comme les deux bateaux ne peuvent pas réellement interagir entre eux autrement qu'en modifiant leur position l'un par rapport à l'autre, le MJ déclare que les Tests entrepris pour poursuivre doivent l'être tous les 10 Rounds et que leurs effets doivent être multipliés par dix jusqu'à ce que d'autres interactions deviennent possibles. Le MJ détermine que la distance initiale entre les vaisseaux est de 500 mètres et que les conditions sont un temps dégagé en haute mer dans un espace ouvert. Il donne à la caraque une longueur d'avance de 50 (Distance).

La caraque est armée d'un canon moyen tourné vers sa poupe, avec une portée de 75 mètres. Le MJ décide que si le langskip réduit la Distance à 21, les Tests seront effectués à chaque Round, car la caraque pourra alors commencer à tirer sur son Poursuivant avec son canon à Portée Extrême.

Si la caraque parvient à faire monter la Distance à 70, elle s'échappe. Les navires effectuent tous les deux des Tests de Navigation, en consultant le tableau en page 109 pour déterminer leur distance relative.

Comme les vaisseaux comportent tous les deux un grand équipage, ils peuvent entreprendre des Tests d'équipage (voir page 121) pour déterminer leur succès sur les Tests de Navigation.

Le vent (voir page 107) va également influencer les choses, car sa direction et sa force peuvent affecter le M des deux vaisseaux, mais surtout celui de la caraque.

Dans le cas qui nous occupe, le langskip réduit la Distance à 21 et les Tests de Poursuite sont donc effectués une fois par Round à partir de ce moment. La caraque peut à présent tirer avec son canon (et si la Distance est encore réduite, d'autres armes à projectiles pourraient intervenir).

L'équipage de la caraque ferait mieux d'espérer parvenir à infliger suffisamment de Dégâts au langskip pour le forcer à abandonner la Poursuite avant qu'il réduise la Distance à 0, sans quoi une collision, suivie d'un abordage déterminé, est malheureusement inévitable.

# **Indices de Collision**

Les navires et beaucoup de périls ont des Indices de Collision. Ces Indices varient en fonction de la masse et de la solidité du bateau ou de l'objet concerné. Pour plus de simplicité, les éléments impliqués dans la collision sont tous appelés des bateaux, mais ils pourraient être des rochers, des icebergs, des monstres marins, etc.

L'Indice de Collision se calcule en additionnant le Bonus d'Endurance du bateau et son nombre de Blessures restantes. Donc, un vaisseau possédant une Endurance de 20 et auquel il reste 15 Blessures a un Indice de Collision de 3 (BE=2 + BB=1).

Quand un vaisseau rentre dans un autre, chacun des deux reçoit un nombre de Dégâts égal à l'Indice de Collision de l'autre navire plus le M du navire qui a causé la collision.

# **PÉRILS EN MER**

Les mers du Vieux Monde sont des endroits dangereux, habités par des monstres et sillonnés par les groupes de pillards de nations et d'espèces hostiles. Il existe également des périls plus prosaïques comme ceux présentés par l'environnement lui-même.

# **Échouer**

Certains périls peuvent pousser un bateau à s'*Échouer.* Quand un navire s'est *Échoué*, il s'arrête net. Le vaisseau ne peut plus bouger jusqu'à ce qu'il soit dégagé du péril. Cette tâche nécessite un Test de Force avec une pénalité égale au total de points d'Encombrement du navire et de sa cargaison. N'importe quel nombre de Personnages, de bêtes de somme, etc. peut aider s'ils ont tous assez de cordes pour tirer.

# **Icebergs**

Quand un glacier rencontre la mer, des morceaux de glace et de neige compactées se détachent et forment des icebergs. Les icebergs dérivent au gré du vent ou des courants marins et sont souvent présents dans la Mer des Griffes et dans d'autres océans froids.

Un Iceberg se déplace à une vitesse de M1. La masse d'un Iceberg est très variable, mais en moyenne, il a un Indice de Collision de 25.

# **Débris marins**

Des débris venant d'épaves, de cargaisons perdues ou d'arbres engloutis flottent à la surface de l'océan. Ils sont davantage une gêne qu'un danger, mais ils peuvent se révéler très pénibles pour les petits bateaux.

Les Débris marins se déplacent à une vitesse de M1 et ont un Indice de Collision de 3. S'ils entrent en collision avec un navire, ce dernier a 20 % de chances de s'y empêtrer, ce qui lui impose une pénalité en fonction de sa Taille :

- 0 Bateaux de Taille Minuscule à Petite : –2 DR à Man et –1 M.
- 0 Bateaux de Taille Moyenne à Grande : –1 DR à Man.
- 0 Bateaux de Taille supérieure à Grande : aucun effet.

L'équipage peut dégager le bateau des Débris marins en réussissant un Test étendu de **Force Accessible (+20)** pour un total de 10 DR.

# **Rochers et bas-fonds**

« Rocher » est un terme général pour tout objet dur fixé sur le fond marin, mais assez haut pour s'arrêter soit juste au-dessus, soit juste en dessous de la surface de l'eau. Cela inclut les récifs de corail, les rochers de la Gueule du dragon, les coquilles de gigantesques créatures marines mortes et tout autre élément dur qui pourrait endommager un navire.

La taille et la masse d'un Rocher sont très variables, mais le Rocher moyen possède un Indice de Collision de 47. En cas de collision avec un Rocher, un vaisseau a 20 % de chances de s'*Échouer* dessus.

Les Bas-fonds sont des bancs de petits rochers, de sable ou de boue. Leur taille et leur masse peuvent beaucoup varier d'un cas à l'autre, mais une zone de Bas-fonds typique possède un Indice de Collision de 10. S'il entre en collision avec des Bas-fonds, un bateau a 40 % de chances de s'y *Échouer*.

# **Détroits**

Les Détroits sont des zones de fort courant. Certains Détroits n'ont d'effet que lorsque la marée change tandis que d'autres exercent une force constante.

Les Détroits doivent recevoir une valeur de M représentant la force et la vitesse du courant à l'intérieur.

Avant que le bateau rencontre un Détroit, le MJ doit décider dans quelle direction le courant s'y écoule. Un navire qui traverse un Détroit va être entraîné dans la direction du courant au M du Détroit avant de pouvoir progresser comme il le ferait sans cela.

Dans un Détroit, tous les Tests de Navigation subissent une pénalité indiquée dans le tableau qui suit.

# **Tourbillons**

Les Tourbillons sont des plans d'eau tournante générés par les courants qui y circulent. Comme les Détroits, les Tourbillons ont leur propre valeur de M représentant l'attraction vers le centre. Si un navire atteint le centre, il risque de ne plus pouvoir repartir et les forces exercées par l'eau tournante peuvent le détruire ou le faire couler. Les Tourbillons possèdent deux parties différentes : la zone (le plan d'eau aspiré vers le centre) et le centre (le milieu d'un Tourbillon qui peut infliger des Dégâts à un vaisseau). Les Tourbillons possèdent les Caractéristiques suivantes :

**M :** le courant, le rythme auquel les objets pris dans la zone se déplacent vers le centre.

**Zone :** la Zone comporte deux nombres. Le premier indique à quelle distance en mètres du centre du Tourbillon ce dernier commence à exercer une attraction, et le second sur quelle distance (en M, sur une trajectoire en spirale) un objet voyage à partir du point où il commence à sentir l'attraction jusqu'à ce qu'il atteigne le centre du Tourbillon.

Si un navire entre dans la Zone, il se déplace vers le centre au rythme du M du Tourbillon à chaque Round. Le Personnage à la barre doit réussir un Test de Manœuvre pour que le bateau puisse continuer sa route malgré le Tourbillon. Si le vaisseau arrive à sortir de la Zone indiquée par le premier nombre, il s'échappe. Quiconque nage dans la Zone doit réussir un Test de **Natation Complexe (–10)** sous peine de commencer à se noyer.

**Man :** les Tests de Manœuvre dans la Zone du Tourbillon subissent la pénalité indiquée.

**IC :** l'Indice de Collision au centre du Tourbillon. Le bateau subit des Dégâts identiques à ceux d'une collision à chaque Round jusqu'à ce qu'il s'échappe.

**Évasion :** le Test pour s'échapper du centre du Tourbillon. Si le Personnage à la barre réussit ce Test, le navire peut s'éloigner du centre du Tourbillon. Si cet éloignement suffit à sortir de la Zone du Tourbillon, le vaisseau est en sécurité. Sinon, il risque d'être de nouveau aspiré vers le centre.

**Exemple :** se retrouver piégé dans un Tourbillon peut être une situation compliquée à gérer. Les divers facteurs pouvant jouer un rôle sont abordés ici. Les Tests d'équipage sont mentionnés ci-dessous, mais expliqués en détail dans le chapitre 14.

Une caraque est prise au bord d'un Tourbillon. Ce qui signifie qu'elle se trouve tout au bout d'une spirale faisant un total de 50 M depuis le rebord du Tourbillon jusqu'au centre.

Le M du Tourbillon est de 4, qui est la distance sur laquelle le courant va entraîner un objet stationnaire vers le centre à chaque Round.

La caraque possède un M de 5 avec sa Voile. Comme elle décrit des cercles dans le Tourbillon, le MJ décidé qu'elle va être affectée par un vent arrière au Round 1 et à tous les Rounds impairs suivants, puis par un vent de face au Round 2 et à tous les Rounds pairs suivants.

À chaque Round, le bateau est déplacé de 4 M autour de la zone et vers le centre du Tourbillon. Ce mouvement a lieu avant que tout autre mouvement soit calculé.

Le Personnage à la barre doit réussir un Test de **Manœuvre** à chaque Tour avant que le bateau puisse progresser. Le résultat de ce Test subit un modificateur de –1 DR.

Le Personnage à la barre effectue des Tests de Manœuvre pour diriger le vaisseau en utilisant sa Compétence Voile. Comme la caraque est un grand vaisseau avec beaucoup de membres d'équipage, ils peuvent combiner leurs efforts pour entreprendre un Test d'équipage afin de manœuvrer comme expliqué en page 123. En l'occurrence, les membres d'équipage occupant n'importe lequel des rôles suivants : Capitaine, Navigateur, Marin, Timonier ou Chansonnier pourraient effectuer des Tests et combiner leurs DR. Le Timonier compte ses DR deux fois.

Si le Test de Manœuvre est un succès, le Personnage à la barre peut ensuite entreprendre un Test de **Navigation (ici donc de Voile)** afin de faire progresser le bateau. Il peut être avantagé (ou pénalisé) par des facteurs comme la direction et la force du vent (voir page 107) et les efforts pour Forcer le rythme (voir page 105).

Comme la caraque est un grand vaisseau avec de nombreux membres d'équipage, ils pourraient combiner leurs efforts afin d'effectuer un Test d'équipage pour faire progresser le navire, comme expliqué en page 121. En l'occurrence, les membres d'équipage occupant n'importe lequel des rôles suivants : Capitaine, Chansonnier, Marin, Navigateur ou Timonier pourraient effectuer des Tests et combiner leurs DR. Le Capitaine compterait ses DR deux fois.

Si le bateau sort de la Zone du Tourbillon, il n'a plus de problème, mais s'il est aspiré jusqu'au centre du Tourbillon, il se met à subir des Dégâts de collision.

L'Indice de Collision du Tourbillon est de 8. Cela signifie qu'à chaque Round, la caraque subit un coup infligeant 8 Dégâts, donc 3 Blessures après avoir déduit son Bonus d'Endurance. Comme elle dispose de 90 Blessures, le Tourbillon va mettre beaucoup de temps à la détruire, mais ce dénouement est inévitable si elle ne parvient pas à s'échapper.

Afin de s'échapper, elle doit réussir un Test étendu de **Manœuvre Intermédiaire (+0)** pour un total de 20 DR. Le Personnage à la barre effectue des Tests de Voile pour accumuler ces DR, mais des Tests d'équipage pour manœuvrer peuvent aussi être effectués à la place.

Si le Test de Manœuvre est un succès, le Personnage à la barre peut ensuite entreprendre un Test de Navigation afin de savoir à quel point le navire s'éloigne du centre. S'il s'échappe de la Zone du Tourbillon, il est en sécurité. Sinon, il risque d'être de nouveau aspiré.

# **États** *En flammes*

Les États *En flammes* affectent un navire à peu près de la même manière qu'un personnage. Un bateau subit 1 Blessure par tour et par État *En flammes*. Un seul et même État *En flammes* ne peut affecter qu'une seule Localisation du vaisseau à la fois.

Cependant, étant donné que les navires sont souvent fabriqués en bois, transportent des stocks d'explosifs ou utilisent des substances inflammables comme la poix pour maintenir leur étanchéité, un incendie peut vite échapper à tout contrôle. Pour savoir à quel point le feu se développe, déterminez l'intensité initiale du brasier, à savoir le nombre d'États *En flammes* faisant effet sur une Localisation donnée (autre que l'Équipage). À la fin de chaque Tour, lancez le dé dans le tableau Intensité du feu pour savoir si les flammes se répandent ou deviennent plus vives.

Si un incendie éclate dans la cale abritant la cargaison, il peut vite gâter les marchandises. Chaque État *En flammes* gâte 1d10 points d'Encombrement de cargaison par Tour, sauf si cette cargaison est résistante au feu et à la fumée pour une raison quelconque.

# **Tirs de petites armes contre un navire**

Généralement, les tirs de petites armes, c'est-à-dire d'armes à projectiles qui ne sont pas des pièces d'artillerie, n'infligent pas assez de Dégâts pour avoir un effet sur un vaisseau. Cela dit, les tirs de petites armes visant un navire ont une chance de blesser l'équipage, donc cela peut valoir la peine de lancer les dés pour les tirs de petites armes visant le bateau au cas où ils frapperaient effectivement un matelot exposé.

Le MJ décide si les PNJ qui tirent avec de petites armes visent un membre d'équipage en particulier (ce qui est souvent difficile, car certaines parties du bateau lui fournissent un couvert) ou tirent sur le navire (qui est une cible plus grande mais la plupart des projectiles touchent alors des structures qui ignorent les tirs de petites armes et seuls quelques coups de chance vont frapper les membres de l'équipage). Les Personnages peuvent eux-mêmes décider de tirer de l'une ou l'autre manière.

#### **Attaques de Corps <sup>à</sup> corps contre un navire**

Si des ennemis attaquent directement l'équipage, cette situation est gérée comme une attaque entre personnages. Toute attaque de corps à corps portée contre une autre partie du bateau touche automatiquement et les Personnages qui attaquent un navire au corps à corps peuvent choisir quelle Localisation attaquer, à condition qu'ils puissent atteindre celle choisie.

Les armes de corps à corps ne sont pas conçues pour infliger des Dégâts aux bateaux, mais il est tout de même possible d'en dégrader un de cette manière sur une longue période. Le MJ doit vérifier la Taille du navire attaqué et la taille du personnage qui l'attaque. Le BE du navire est ajusté de la façon indiquée dans le tableau qui suit pour prendre en compte le fait que la plupart des attaques de corps à corps ont beaucoup de mal à infliger des Dégâts significatifs à un vaisseau. Si le résultat est une case sans chiffre, cela signifie que les attaques du personnage concerné n'infligent normalement pas de Dégâts à un bateau. Donc, si un halfling (de Petite Taille) attaque une chaloupe (de Taille Minuscule), le bateau triple son BE pour déterminer s'il subit des Dégâts. Si le même halfling attaque un Grand bateau, il ne pourra lui infliger aucun Dégât.

# **RÉPARER LES NAVIRES**

Les Dégâts infligés à un bateau peuvent être réparés de manière permanente avec un Test réussi de **Métier (Constructeur de navires)**. Métier (Charpentier) peut être utilisé à la place avec une pénalité de –10 sur tous les jets. Le réparateur doit avoir accès aux outils et aux matériaux nécessaires, par exemple des planches de bois, de la poix, de la toile, etc. Les Dégâts infligés à la Coque ne peuvent être réparés de manière permanente que si le vaisseau est traîné en cale sèche ou amené sur un quai sec.

Un constructeur naval local, à savoir un PNJ artisan possédant la Compétence Métier (Constructeur de navires), est présent dans la plupart des ports et répare les vaisseaux pour 1 CO par Blessure restaurée. Chaque Test réussi prend 1d10 heures de travail et restaure 1d10 Blessures sur le navire.

Certaines cultures ont des traditions de construction navale différentes des autres. Par exemple, les constructeurs de navires norses ne connaissent pas les techniques nécessaires pour bâtir des vaisseaux dotés d'un gaillard et d'un château de poupe et se spécialisent dans les coques construites à clins à la place. Ils ne peuvent donc pas réparer correctement les bateaux autres que les coracles, les chaloupes, les knarrs, les langskips et les vaisseaux au modèle similaire, mais ils pourraient tout de même réparer temporairement les embarcations d'un autre type.

# **Réparations temporaires**

Il est possible d'entreprendre des réparations temporaires sans amener le bateau en cale sèche. Le Test de **Métier (Constructeur de navires)** ou de **Métier (Charpentier)** pour cela va de **Complexe (–10)** à **Très Difficile (–30)** en fonction des conditions de travail. Si ce Test est un succès, chaque réparation prend une heure et restaure 1d10 Blessures.

Cependant, le navire doit effectuer un Test d'Endurance pour chaque jour complet de voyage après les réparations temporaires. Il doit également effectuer ce Test chaque fois qu'un Test de Manœuvre doit avoir lieu. Chaque Test raté inflige 1d10–4 Dégâts, car la réparation temporaire cède.

# **CRITIQUES SUR UN NAVIRE**

Quand un jet d'attaque réussi contre un bateau donne un double, il subit un Critique. De plus, tous les coups qui touchent une fois que le score de Blessures d'un vaisseau est tombé à 0 sont des Critiques. Il existe différents modèles de bateau et la description d'un Critique donné peut ne pas s'appliquer au vaisseau concerné. Dans ce cas, utilisez le Critique le plus proche en termes de gravité.

# **Critiques sur l'équipage**

Les Blessures Critiques sur l'Équipage fonctionnent en suivant les règles de **WFJDR** (page 172) ou du supplément **Aux Armes !** (page 80).

# **Critiques sur un navire**

Quand le navire subit une Blessure Critique, déterminez la Localisation endommagée, lancez les dés dans le tableau des Critiques pour cette Localisation et appliquez les effets. En plus des effets indiqués dans le tableau, certains types de Dégâts peuvent avoir des effets particuliers.

# **Éclats (Indice)**

Pendant un combat naval, l'équipage subit beaucoup de blessures à cause de volées d'éclats de bois. Si un Critique donne des Éclats, alors un nombre de membres d'équipage égal à l'Indice sont touchés et subissent 9 Dégâts.

### **Voie d'eau (Indice)**

Un vaisseau percé d'une Voie d'eau prend l'eau. Le MJ doit ajouter l'Indice à un total cumulé qui augmente à chaque Round. Si cet Indice atteint la moitié du score d'Endurance du bateau, le vaisseau perd 1 M et subit une pénalité de –1 DR sur tous les Tests de Navigation, car il est alourdi par l'eau. Sauf si la cargaison est étanche, elle perd 1d10 % de sa valeur par Tour jusqu'à ce que la voie d'eau soit réparée et la cale écopée. À ce stade, tous les Sabords doivent être fermés sinon l'Indice augmente de 1.

Quand l'Indice devient égal au score d'Endurance du navire, il coule.

L'équipage peut tenter de faire baisser l'Indice en écopant l'eau. Chaque membre d'équipage qui se consacre à écoper pendant dix Rounds peut effectuer un Test de **Force Intermédiaire (+0)**. Pour chaque DR positif qu'il génère sur ce Test, il peut réduire le total cumulé de 1.
