# Planches de référence du monde affine

Ce dossier contient cinq planches du monde affine.
`scripts/qc/capture-jeu.mjs` affiche celles référencées par ses cinq scènes à côté des captures actuelles.
Les captures du monde volumique et leur comparaison
sont produites dans `public/qc/jeu/` par :

```bash
node scripts/qc/capture-jeu.mjs
```

| Fichier | Vue de référence |
|---|---|
| `env-siege-explore.png` | Enceinte explorable, rotations isométriques, dessus et POV |
| `env-arene-hub.png` | Bourg de l’arène, rotations isométriques, dessus et POV |
| `env-test-opera-theatre.png` | Théâtre, rotations isométriques, dessus et POV |
| `env-test-piege-caveau.png` | Caveau piégé, rotations isométriques, dessus et POV |
| `diligence.png` | Auberge, deux niveaux, rotations et plans de zones |

Le comparateur affiche les planches de référence à côté des captures actuelles.
